# 🌐 Portafolio Personal - GitHub Pages

Este repositorio contiene el código fuente de mi sitio web personal y portafolio profesional, alojado y desplegado de forma continua a través de [GitHub Pages](https://pages.github.com/). Este espacio centraliza mis desarrollos en infraestructura de redes, virtualización, automatización de servidores y sistemas embebidos.

## 🔗 Vista en Vivo

Puedes explorar el portafolio interactivo aquí: **[https://Nxhym.github.io](https://Nxhym.github.io)**

## 🚀 Características del Sitio

* **Exhibición de Proyectos:** Catálogo detallado de mis implementaciones tecnológicas, abarcando desde arquitecturas con Proxmox y pfSense hasta telemetría con protocolos SCADA e IoT.
* **Diseño Responsivo (Mobile-First):** Interfaz adaptada para mantener la legibilidad y la estructura visual en cualquier dispositivo.
* **Integración y Despliegue (CI/CD):** El sitio se actualiza automáticamente en producción tras cada *commit* en la rama principal.

## 🛠️ Stack Tecnológico

* **Estructura y Diseño:** HTML5, CSS3.
* **Interactividad:** JavaScript.
* **Despliegue:** GitHub Pages.
